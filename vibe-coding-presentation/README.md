# Vibe Coding 經驗分享簡報

這是一份網頁式簡報，主題是「Vibe Coding 經驗分享」，內容以 `skill-build-interactive-science-lesson/SKILL.md` 的工作流作為案例，從定義、原理、工具、實作示範到 GitHub Pages 佈署。

## 使用方式

- 直接用瀏覽器開啟 `index.html`。
- 使用左右方向鍵、PageUp/PageDown、空白鍵切換投影片。
- 左側目錄可直接跳到指定頁。

## 檔案

- `index.html`：30 頁投影片內容。
- `styles.css`：簡報視覺、RWD 與投影版面。
- `script.js`：投影片切換、頁碼、進度條與 hash 路由。

## 佈署到 GitHub Pages

如果要把這份簡報放到 GitHub Pages，可將本資料夾內容放在 repo 根目錄或 `docs/` 資料夾，推送到 GitHub 後，在 Settings → Pages 選擇對應分支與目錄。
