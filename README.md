# 毛細現象探究實驗室

國小三年級自然領域「毛細現象」探究與實作互動教材。

## 教材內容

- 毛細現象觀察動畫
- 三個探究任務：不同材質、不同層數、不同寬度
- 互動實驗室：選擇紙材、層數、寬度與觀察時間
- 學生數據輸入與長條圖
- 三年級版原理解釋
- 6 題即時回饋測驗

## 預設數據

教材內建以下預設數值，學生可改成自己的實測數據：

- 衛生紙：15 mL
- 廚房紙巾：52 mL
- 一層廚房紙巾：10 mL
- 四層廚房紙巾：40 mL
- 細廚房紙巾：11 mL
- 寬廚房紙巾：15 mL

## 使用方式

直接開啟 `index.html`，或部署到 GitHub Pages。

建議課堂流程：

1. 使用「觀察站」投影導入。
2. 讓學生在「探究任務」先做預測。
3. 到「互動實驗室」調整條件並觀察。
4. 在「我的圖表」輸入實測數據。
5. 完成「挑戰測驗」。
