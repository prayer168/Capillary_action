# 自然學習重點整理互動網站

這是一個多頁式自然學習互動網站，以「森林水循環」作為範例，示範學生如何從自然知識文章整理重點。

## 網站頁面

- `index.html`：網站首頁與學習流程
- `reading.html`：文章劃重點互動練習
- `grid.html`：九宮格重點整理範例
- `mindmap.html`：心智圖概念關聯範例
- `applications.html`：生活應用與概念檢核
- `references.html`：參考網站與資料
- `downloads.html`：空白學習單下載
- `worksheet-grid.html`：空白九宮格可列印版
- `worksheet-mindmap.html`：空白心智圖可列印版

## 學習單

下載檔案放在 `downloads/`：

- `blank-nine-grid.pdf`
- `blank-mind-map.pdf`
