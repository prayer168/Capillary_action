# 森林水循環重點整理互動學習站

這是一份靜態網頁互動教材，協助學生從自然知識文章延伸到完整的重點整理流程。

## 學習流程

1. 文章劃重點：空白閱讀、自己練習、示範重點。
2. 九宮格整理：整理九個核心概念。
3. 心智圖：建立概念之間的關係。
4. 應用與範例：連結校園、山坡地、乾旱和家庭節水。
5. 概念檢核：三題選擇題確認理解。
6. 參考網站：提供教師備課和學生延伸閱讀來源。

## 主要互動

- 點選文章重點並檢核答案。
- 點選九宮格查看摘要說明。
- 點選心智圖節點查看概念連結。
- 完成概念檢核題並得到回饋。
